# JTripathy4 GFPGAN Colab

Colab workflow for GFPGAN v1.4 photo restoration.

Use Colab runtime 2025.07 / Python 3.11.

Original photos are saved to:
Drive/GFPGAN/input

Restored photos are saved to:
Drive/GFPGAN/result

Google Drive files are never deleted.
Only temporary Colab server files are cleared.
